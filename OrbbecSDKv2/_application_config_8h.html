OB_EXPORT ob_application_config * ob_device_get_application_config ( ob_device * device,
ob_error ** error )

Get the application runtime configuration cache for the device.

Parameters
[in]deviceThe device object.
[out]errorPointer to an error object that will be set if an error occurs.
Returns
ob_application_config* The application configuration object cached by the device.
Attention
If the device has no application configuration cache, the SDK creates one with default values.
Changes made through the returned config update the device cache directly.
The returned config should be released by calling ob_delete_application_config.
