Detailed Description

Extensible options for activating a private filter instance.

Passed to ob_filter_activate_private_ex / ob_priv_filter_activate_ex. New fields must only be appended at the end. The caller sets struct_size to sizeof(ob_priv_filter_activate_options); the callee uses it to detect which fields a (possibly older) caller actually provided, keeping the ABI compatible as the struct grows. This is the single extension point for future activation parameters.
